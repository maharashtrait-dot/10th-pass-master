VISUAL LEARNING ENGINE V1

What this adds
- Automatic small black-and-white visual beside Answer/Keywords.
- Internal SVG asset library (no external hotlinks required).
- Works in normal Chapter Questions and My Revision.
- Mobile-friendly and print-friendly.
- Matching uses question text + easy answer + keywords + subject + chapter name.
- If no relevant internal visual is found, the app shows no unrelated image.

Included visual families
- Geography: field visit, location/grid, physiography/drainage, climate/monsoon,
  vegetation/wildlife, population, settlement, economy, tourism, transport.
- Mathematics: probability, linear graph, Pythagoras, circle, trigonometry.
- Science: gravitation, periodic table, reaction, circuit, heat, refraction, lens,
  carbon, space, DNA, cell, heart/circulation, food chain, microbiology,
  green energy, disaster management.
- History/Civics/Language: timeline, democracy, keyword-memory helper.

How to test
1. Replace project files with this ZIP.
2. Restart backend: node server.js
3. Open: http://localhost:3001/index.html
4. Login and open a subject/chapter.
5. Open a question and click Show Answer.
6. For a matched concept/chapter, "चित्रातून लक्षात ठेवा" and a small B/W visual appears.
7. Also test My Revision -> Show Answer.

Safety / quality rule
- This V1 never fetches random web images.
- All visuals come from frontend/assets/visuals inside the app.
- More textbook-specific diagrams/maps can be added to this internal library later.
