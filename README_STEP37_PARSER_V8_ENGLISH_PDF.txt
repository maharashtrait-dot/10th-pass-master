This build is based on the verified English Mathematics-I (Algebra), March 2025 style of Board PDF.

- Preserves structure such as 1(A)(i), 1(B)(i), 2(A)(i), 2(B)(i), 3(A)(i), 3(B)(i), 4(i), 5(i).
- Does not treat MCQ options (A)-(D) as new questions.
- Ignores page headers/footers such as N 619 and P.T.O.
- Removes MCQ option text from Q.1(A) stems.
- Assigns the expected per-subquestion marks for the extracted Board structure.
- Keeps the existing OCR fallback and review-before-import safety rule.
