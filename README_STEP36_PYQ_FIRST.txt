10th PASS MASTER — STEP 36 PYQ-FIRST / AUTHENTIC BOARD QUESTION BANK

Purpose
-------
The app now separates authentic Board PYQs from PYQ-based, Important and Practice questions.
An existing question is NEVER automatically relabelled as ACTUAL_PYQ.

Student features
----------------
1. Chapter questions show source badges:
   ACTUAL PYQ / REPEATED PYQ / PYQ-BASED / IMPORTANT / PRACTICE
2. Chapter page has a Source filter.
3. Student menu has “PYQ First – PASS Priority”.
4. Daily smart questions and Smart Revision already prioritize PYQ content.
5. Mock Test selection prioritizes verified PYQ content when available.

Admin features
--------------
1. Select a verified PYQ CSV in Admin > STEP 36.
2. Click IMPORT VERIFIED PYQ CSV.
3. Click CHECK PYQ STATUS.

CSV columns
-----------
subject_name,chapter_number,question_text,pyq_year,pyq_exam_month,pyq_paper_set,marks,hint,easy_answer,keywords,difficulty,pyq_frequency,visual_tag,source_note,question_paper_id

IMPORTANT AUTHENTICITY RULE
---------------------------
Only import a question as an actual PYQ when it has been verified against a real Maharashtra SSC Board question paper.
The importer automatically marks imported rows as ACTUAL_PYQ and pyq_verified=TRUE.
Do not use the importer for AI-created practice questions.

Current limitation
------------------
This ZIP does not invent or label questions as Board PYQs. Actual PYQ text must come from verified Board papers. The official MSBSHSE question-paper portal is the preferred source.

Recommended PASS hierarchy
--------------------------
ACTUAL_PYQ -> PYQ_REPEATED -> PYQ_BASED -> IMPORTANT -> PRACTICE

Visual Learning
---------------
Every imported PYQ can carry a visual_tag so the existing Visual Learning engine can show a relevant internal black-and-white visual.
