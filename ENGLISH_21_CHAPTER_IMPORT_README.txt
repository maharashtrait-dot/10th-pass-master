for English chapters 1.4 through 4.6 (21 chapters).

HOW TO USE:
1. Replace the corresponding project files with this ZIP and restart the backend.
2. Open Admin Panel.
3. Go to “English – Remaining 21 Chapters”.
4. Click “PREVIEW REMAINING 21 CHAPTERS”.
5. Confirm 21 chapter files / 420 questions.
6. Click “IMPORT ALL 420 QUESTIONS”.

The importer checks chapter + exact question text and skips an already-existing question.
