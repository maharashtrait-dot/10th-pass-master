STAGE 10 STEP 24 – AUTOMATIC MCQ EXAM SYSTEM

This step upgrades the earlier self-assessment mock test into an automatic MCQ system.

Features:
- Questions support options A/B/C/D, correct option and explanation.
- Admin MCQ readiness report shows how many MCQ-ready questions each subject has.
- Admin can load active questions and save the four options + correct answer.
- Student mock test uses only MCQ-ready questions, 20 questions and 30 minutes.
- Automatic checking calculates Correct, Wrong, Unanswered and Score %.
- 40% is used as the app's pass-readiness threshold for this mock test.
- Existing questions are NOT automatically given fake answers; they must be prepared as real MCQs in Admin.

IMPORTANT:
The 20-question target and 40% threshold are app design choices, not a claim about official Maharashtra SSC paper pattern or Board passing rules.
