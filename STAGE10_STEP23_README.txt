STAGE 10 – STEP 23
MOCK TEST SYSTEM

Features:
- Subject-wise 20-question random mock test.
- 30-minute timer in the student UI.
- Student marks each question as I Know This or Need Revision.
- Submission stores test history and calculates a self-assessment percentage.
- Unanswered questions are treated as Need Revision on submit.
- Requires at least 20 active questions in the selected subject.

IMPORTANT:
This is a PASS-oriented self-assessment mock system, not an official Maharashtra SSC Board exam simulator. The current question schema does not store MCQ options/correct answers, so the score is based on the student self-assessment rather than automatic answer-key evaluation.
